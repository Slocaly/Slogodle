# Guess the Logo

A daily logo-guessing game built with TanStack Start (React + TypeScript).

## Commands

| Command          | Action                                |
| :---------------- | :------------------------------------ |
| `pnpm run dev`     | Starts the dev server                 |
| `pnpm run build`   | Production build                      |
| `pnpm run start`   | Preview a production build            |
